# 파트너 영상 배포

관리자 `/op/videos`에서 제목과 MP4 원본을 등록하고, 확인 후 공개한다.
파트너는 내 작업실의 ‘영상 받기’에서 등록 이름을 입력한다. 선착순 한 명에게
배정하며, 다른 파트너 목록에서는 사라진다. 열어 둔 카드 목록은 2.5초마다 갱신한다.
동시에 눌러도 DB 조건부 UPDATE로 한 명만 배정한다.

다운로드 요청 시점에 배정한다. 브라우저의 저장 완료 여부는 판단하지 않는다.
연결이 끊겨도 같은 활성 계정은 ‘내가 받은 영상’에서 다시 받는다.
일시정지·강퇴 계정의 접근은 기존 포털 정책대로 차단한다.
관리자는 수령 당시 이름과 시각을 확인한다. 계정 삭제 후에도 이 기록과
배정 상태는 보존하며, 다른 사람에게 다시 배포하지 않는다.

원본은 공개 자료실이나 Git에 넣지 않는다. SQLite 전용 서버의
`data/private_videos/`(또는 `FP_VIDEO_DIR`)에 저장한다. 최대 512MB MP4,
동일 SHA256 파일은 중복 등록하지 않는다. DB와 비공개 파일 디렉터리를
함께 백업해야 한다. 외부 정적 파일 서버에 이 디렉터리를 연결하지 않는다.
PostgreSQL/서버리스 업로드는 지원하지 않는다.

검증: `python3 -m unittest discover -s tests -p test_video_library.py -q`
테스트는 임시 DB/파일과 직접 생성한 HTTP 서버를 사용한다.
운영 watchdog 또는 문자 발송은 실행하지 않는다.

대시보드와 영상 목록은 실제 영상 썸네일 카드로 표시한다. 카드 선택만으로는
배정하지 않으며, 이름을 입력하고 수령 버튼을 눌러야 배정한다.
새 관리자 업로드는 브라우저에서 JPEG 썸네일도 자동 추출한다. 썸네일은
비공개 원본 옆에 저장하며, 미배정 공개 영상 또는 수령자/관리자에게만 제공한다.

영상별 캡션은 DB `video_captions`가 정본이다. 관리자 영상 배포 화면에서
편집하며 원본 SHA 확인 후 저장한다. 스크립트의 핵심 내용을 유지하고
구독/프로필 안내를 댓글 키워드 CTA로 바꾼다. 새 영상 배포 때 캡션도 함께 등록한다.
수령 직후와 ‘내가 받은 영상’에서 캡션을 복사할 수 있다. 기존 수령자에게도
업데이트된 캡션이 표시되며, 미수령자에게는 캡션 원문을 제공하지 않는다.

신규 수령 한도는 `fp/video_library.py`의 `DAILY_VIDEO_LIMIT`가 정본이다.
계정당 한국 시간 기준 하루 1편이며, 자정에 초기화한다. 기존 수령 이력도
포함한다. 이미 받은 원본/캡션을 다시 받는 것은 한도를 소비하지 않는다.
SQLite는 BEGIN IMMEDIATE, PostgreSQL은 계정 행 잠금으로 한도 확인과
배정을 한 트랜잭션에서 처리해 서로 다른 영상의 동시 선점을 막는다.
기존 배정은 회수하거나 다른 계정으로 옮기지 않는다.
